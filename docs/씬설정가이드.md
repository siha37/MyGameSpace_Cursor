# Unity 씬 설정 가이드

이 문서는 TestRoom 씬을 처음부터 구성하는 방법을 설명합니다.

## 1. 프로젝트 설정

### 레이어 추가
Edit > Project Settings > Tags and Layers

- Layer 6: `Ground`
- Layer 7: `Enemy`
- Layer 8: `Player`

### Physics 2D 설정
Edit > Project Settings > Physics 2D

- Gravity Y: `-20`
- Layer Collision Matrix: **Player × Enemy 체크 해제** (통과, 악셀 쿼리는 유지)

### 마찰 0 재질
`Assets/Physics/NoFriction.physicsMaterial2D`
- Friction: `0`
- Bounciness: `0`
- Player Rigidbody2D / CapsuleCollider2D와 모든 Ground 콜라이더에 적용
- 점프·이동으로 벽에 닿아도 달라붙지 않게 한다. 1초 부착은 악셀 도달만.

## 2. 씬 생성

Assets/Scenes 폴더에 새 씬 생성: `TestRoom.unity`

## 3. 카메라 설정

Main Camera 선택:
1. Position: `(0, 1, -10)`
2. Projection: `Orthographic`
3. Size: `4.8`
4. Add Component: `Smooth Follow Camera`
   - 나중에 Player를 Target으로 설정

## 4. 플레이어 생성

### GameObject 생성
Hierarchy > Create Empty: `Player`
- Position: `(0, -1.5, 0)`
- Tag: `Player`
- Layer: `Player`

### 컴포넌트 추가

#### Rigidbody2D
- Body Type: `Dynamic`
- Gravity Scale: `1`
- Constraints: `Freeze Rotation Z`

#### Capsule Collider 2D
- Size: `(1.0, 1.2)` (비율 1:1.2)
- Offset: `(0, 0.6)` (중심을 발 위치로)
- Material: 마찰 0 Physics Material 2D

#### Player Controller
- Add Component: `Player Controller`
- 나중에 Respawn Point 설정

#### Pressure Gauge
- Add Component: `Pressure Gauge`
- (자동으로 추가됨)

#### Visual (자식 오브젝트)
Hierarchy > Player > Create > 2D Object > Sprite
- Name: `Visual`
- Sprite: 임시로 기본 사각형
- Color: 파란색
- Scale: `(1.0, 1.2, 1)`

## 6. 허수아비 생성

### 기본 허수아비
Hierarchy > Create Empty: `Dummy_1`
- Position: `(16, -0.85, 0)` (Platform_Step 위)
- Layer: `Enemy`
- Tag: `Enemy`

#### 컴포넌트 추가
- Add Component: `Rigidbody 2D`
  - Body Type: `Dynamic`
  - Gravity Scale: `1`
  - Constraints: `Freeze Rotation Z` (지상 좌우 추적)
- Add Component: `Dummy`
- Add Component: `Box Collider 2D`
  - Size: `(1.0, 1.2)`
  - Offset: `(0, 0.6)`
  - Is Trigger: 꺼짐 (지면과 충돌해 착지)
- Physics 2D: Player 레이어와 Enemy 레이어 충돌 무시 (P는 통과, 악셀 판정은 유지)

#### Visual (자식 오브젝트)
- Create > 2D Object > Sprite
- Name: `Visual`
- Color: 빨간색
- Scale: `(1.0, 1.2, 1)`
- Dummy 컴포넌트의 Visual Object에 드래그

#### FrontMarker (전방 테두리)
- Create > 2D Object > Sprite
- Name: `FrontMarker`
- Color: **노란색** (몸통 빨강과 구분)
- Scale: `(0.18, 1.28, 1)`
- Position: 몸통 전방 끝 `(0.5, 0.6, 0)` (좌우 전환 시 Dummy가 이동)
- Dummy 컴포넌트의 Front Marker에 드래그
- 전방 = 이동 방향. 노란 테두리로 현재 전방을 본다.

넓은 간격으로 배치한다. 저장된 바닥 더미는 유지한다.
- `Dummy_2`: Position `(-40, -1.5, 0)` (좌측 먼 평지, 국소 천장 아래)
- `Dummy_3`: Position `(-24, -1.5, 0)` (좌측 평지)
- `Dummy_4`: 씬에 저장된 바닥 위치
- `Dummy_5`: Position `(18, 2.7, 0)` (Floor_L1)
- `Dummy_6`: Position `(-16, 6.9, 0)` (Floor_L2)
- `Dummy_7`: Position `(8, 11.1, 0)` (Floor_L3)
- `Dummy_8`: Position `(-8, 15.3, 0)` (Floor_L4)

거리 8 안에 들어오기 전에는 추적하지 않는다. 죽으면 다시 생성하지 않는다.

## 8. UI 설정

### Canvas 생성
Hierarchy > Create > UI > Canvas
- Render Mode: `Screen Space - Overlay`

### 게이지 패널
Canvas > Create > UI > Panel
- Name: `GaugePanel`
- Anchor: 좌상단
- Position: `(150, -50, 0)`
- Size: `(250, 80)`

#### Background
GaugePanel에 이미 Image 컴포넌트 있음
- Color: 반투명 검정 `(0, 0, 0, 150)`

#### Fill
GaugePanel > Create > UI > Image
- Name: `Fill`
- Anchor: Stretch (좌우상하 늘림)
- Margins: `(10, 10, 10, 10)`
- Image Type: `Filled`
- Fill Method: `Horizontal`
- Fill Amount: `1`
- Color: 주황색 `(255, 150, 0, 255)`

#### Text
GaugePanel > Create > UI > Text
- Name: `GaugeText`
- Anchor: Center
- Position: `(0, 0, 0)`
- Text: `"4.0 / 5.0"`
- Font Size: `24`
- Alignment: Center
- Color: 흰색

### GaugeUI 컴포넌트
GaugePanel 선택:
- Add Component: `Gauge UI`
- Gauge: Player의 `Pressure Gauge` 드래그
- Fill Image: `Fill` 드래그
- Gauge Text: `GaugeText` 드래그

### Help 버튼 / 조작법 팝업
Canvas에 `HelpUI` 컴포넌트. Play 시 자동 생성되기도 한다.

- `HelpButton`: 우측 상단, 텍스트 `HELP`
- `HelpPopup`: 반투명 오버레이 + 중앙 패널 `조작법`
- 닫기: `닫기` 버튼, Esc, 바깥 클릭
- 팝업이 열려 있으면 일시정지

## 9. 카메라 타겟 설정

Main Camera 선택:
- Smooth Follow Camera > Target: `Player` 드래그

## 10. 테스트

Play 버튼을 눌러 테스트:
- [ ] WASD로 이동
- [ ] A/D 홀드로 질주 (게이지 충전)
- [ ] Space로 점프
- [ ] Shift + 방향키로 8방향 악셀
- [ ] 점프로 벽에 닿으면 미끄러짐
- [ ] 악셀로 허수아비 처치
- [ ] 게이지 확인
- [ ] 우측 상단 HELP로 조작법 팝업

## 트러블슈팅

### 플레이어가 떨어짐
- Ground 레이어 확인
- Box Collider 2D 추가 확인

### 악셀이 안 됨
- Pressure Gauge 컴포넌트 확인
- 게이지가 충분한지 확인

### 악셀이 안 맞음
- Enemy 레이어 확인
- Dummy 컴포넌트 확인
- IDamageable 인터페이스 구현 확인
- 커서가 캐릭터와 겹치지 않는지 확인

### 카메라가 안 따라감
- Smooth Follow Camera 컴포넌트 확인
- Target이 설정되었는지 확인

# Unity 씬 설정 가이드

이 문서는 TestRoom 씬을 처음부터 구성하는 방법을 설명합니다.

## 1. 프로젝트 설정

### 레이어 추가
Edit > Project Settings > Tags and Layers

- Layer 6: `Ground`
- Layer 7: `Enemy`
- Layer 8: `Player`

### Physics 2D 설정
Edit > Project Settings > Physics 2D

- Gravity Y: `-20`

## 2. 씬 생성

Assets/Scenes 폴더에 새 씬 생성: `TestRoom.unity`

## 3. 카메라 설정

Main Camera 선택:
1. Position: `(0, 0, -10)`
2. Projection: `Orthographic`
3. Size: `5`
4. Add Component: `Smooth Follow Camera`
   - 나중에 Player를 Target으로 설정

## 4. 플레이어 생성

### GameObject 생성
Hierarchy > Create Empty: `Player`
- Position: `(0, 0, 0)`
- Tag: `Player`
- Layer: `Player`

### 컴포넌트 추가

#### Rigidbody2D
- Body Type: `Dynamic`
- Gravity Scale: `1`
- Constraints: `Freeze Rotation Z`

#### Capsule Collider 2D
- Size: `(0.5, 1.8)`
- Offset: `(0, 0.9)` (중심을 발 위치로)

#### Player Controller
- Add Component: `Player Controller`
- 나중에 Respawn Point 설정

#### Pressure Gauge
- Add Component: `Pressure Gauge`
- (자동으로 추가됨)

#### Visual (자식 오브젝트)
Hierarchy > Player > Create > 2D Object > Sprite
- Name: `Visual`
- Sprite: 임시로 기본 사각형
- Color: 파란색
- Scale: `(0.5, 1.8, 1)`

## 6. 허수아비 생성

### 기본 허수아비
Hierarchy > Create Empty: `Dummy_1`
- Position: `(5, -1, 0)`
- Layer: `Enemy`
- Tag: `Enemy`

#### 컴포넌트 추가
- Add Component: `Dummy`

Player > Player Controller:
- Respawn Point: `RespawnPoint`를 드래그

## 8. UI 설정

### Canvas 생성
Hierarchy > Create > UI > Canvas
- Render Mode: `Screen Space - Overlay`

### 게이지 패널
Canvas > Create > UI > Panel
- Name: `GaugePanel`
- Anchor: 좌상단
- Position: `(150, -50, 0)`
- Size: `(250, 80)`

#### Background
GaugePanel에 이미 Image 컴포넌트 있음
- Color: 반투명 검정 `(0, 0, 0, 150)`

#### Fill
GaugePanel > Create > UI > Image
- Name: `Fill`
- Anchor: Stretch (좌우상하 늘림)
- Margins: `(10, 10, 10, 10)`
- Image Type: `Filled`
- Fill Method: `Horizontal`
- Fill Amount: `1`
- Color: 주황색 `(255, 150, 0, 255)`

#### Text
GaugePanel > Create > UI > Text
- Name: `GaugeText`
- Anchor: Center
- Position: `(0, 0, 0)`
- Text: `"2.0 / 4.0"`
- Font Size: `24`
- Alignment: Center
- Color: 흰색

### GaugeUI 컴포넌트
GaugePanel 선택:
- Add Component: `Gauge UI`
- Gauge: Player의 `Pressure Gauge` 드래그
- Fill Image: `Fill` 드래그
- Gauge Text: `GaugeText` 드래그

## 9. 카메라 타겟 설정

Main Camera 선택:
- Smooth Follow Camera > Target: `Player` 드래그

## 10. 테스트

Play 버튼을 눌러 테스트:
- [ ] WASD로 이동
- [ ] A/D 2연타로 달리기
- [ ] Space로 점프
- [ ] Shift + 방향키로 악셀
- [ ] 마우스 좌클릭으로 공격
- [ ] 허수아비 처치
- [ ] 게이지 확인

## 트러블슈팅

### 플레이어가 떨어짐
- Ground 레이어 확인
- Box Collider 2D 추가 확인

### 악셀이 안 됨
- Pressure Gauge 컴포넌트 확인
- 게이지가 충분한지 확인

### 공격이 안 맞음
- Enemy 레이어 확인
- Dummy 컴포넌트 확인
- IDamageable 인터페이스 구현 확인

### 카메라가 안 따라감
- Smooth Follow Camera 컴포넌트 확인
- Target이 설정되었는지 확인

## 1. 개요

| 항목 | 내용 |
|------|------|
| 플랫폼 | Windows |
| 엔진 | Unity |
| 장르 | 2D 횡스크롤 스타일리시 액션 |
| 레퍼런스 | 카타나 제로 (Katana ZERO) |
| 시점 | 사이드 뷰, 횡 스크롤 |
| 핵심 톤 | 빠르고, 심플하고, 한 번의 실수가 곧 죽음 |

한 판의 전투는 **짧은 판단 → 즉각 처형 → 다음 이동**으로 끝난다.  
복잡한 콤보나 HP 막기보다, **위치·방향·타이밍**만으로 승부가 갈리게 한다.

## 2. 코어 디자인

### 2.1 디자인 포인트

- **스피드**: 이동, 달리기, 악셀, 공격이 모두 즉각적으로 반응한다.
- **심플함**: 입력은 적고, 규칙은 명확하다. 한 대면 죽는다.
- **스타일리시**: 악셀 궤적, 방향 전환의 관성, 벽/천장 고정이 시각적  ritm을 만든다.

### 2.2 플레이 루프 (한 구간)

```
진입 → 경로 파악 → 접근/유인 → 공격 또는 악셀로 처형 → 공압 회복 → 다음 구간
```

실패 조건은 단순하다. 피격 1회 = 사망 (특수 유닛 제외).

### 2.3 용어

| 용어 | 정의 |
|------|------|
| P | 플레이어블 캐릭터 |
| 유닛 | P와 적군 AI를 포함한 모든 캐릭터 |
| 특수 유닛 | 보스/스토리 특화 유닛. 즉사 규칙의 예외 |
| 전방 | 해당 유닛이 현재 바라보는 방향 |
| 악셀 | 공압 게이지를 소모하는 8방향 대쉬 |
| 공압 게이지 | 악셀 자원. `float`로 점진 충전 |
| 악셀 역분사 | 악셀 도중 반대 방향 재악셀로 대쉬를 끊는 기술 |
| 부착 | 악셀로 벽면/천장에 도달했을 때 일정 시간 고정된 상태 |

## 3. 조작

플랫폼: **Windows / 키보드 + 마우스**

| 행동 | 입력 | 비고 |
|------|------|------|
| 이동 | `W` `A` `S` `D` | 기본 보행. 관성 적용 |
| 점프 | `Space` | |
| 달리기 | `A` 또는 `D` 2연타 후 홀드 | 해당 방향 달리기 유지, 공압 충전 |
| 악셀 | `Shift` + 방향 | 8방향. 아래 표 참고 |
| 일반 공격 | 마우스 좌클릭 | 근접. 커서 방향으로 공격 |

### 3.1 악셀 8방향

`Shift`를 누른 채 아래 입력을 넣는다.

| 방향 | 입력 | 벡터 |
|------|------|------|
| 상 | `W` | (0, +1) |
| 하 | `S` | (0, -1) |
| 좌 | `A` | (-1, 0) |
| 우 | `D` | (+1, 0) |
| 좌상 | `A` + `W` | (-1, +1) |
| 우상 | `W` + `D` | (+1, +1) |
| 우하 | `S` + `D` | (+1, -1) |
| 좌하 | `A` + `S` | (-1, -1) |

대각선은 정규화하여 속도 크기를 직교 방향과 동일하게 맞춘다.

## 4. 플레이어 시스템

### 4.1 이동

일반적인 2D 횡스크롤과 같이 `A`/`D`로 좌우 이동한다.

**방향 전환 관성 (필수)**  
우측 이동 중 좌측으로 순간 전환할 때(또는 그 반대) 속도가 즉시 반전되지 않는다.

```
가속 중 → 감속 → 영점 속도(0) → 반대 방향 가속
```

- 감속 구간과 재가속 구간이 체감되어야 한다.
- 짧은 거리의 미세 조작과, 전력 질주 중 급선회의 무게감이 구분되어야 한다.
- 구체 수치는 9장. 카타나 제로보다 약간 묵직하되, 답답하지 않은 수준을 목표로 한다.

`W`/`S`는 악셀·부착 상태에서 방향 입력으로 쓰이며, 지상 기본 이동의 상하 보행에는 사용하지 않는다. (사다리/수직 이동이 추가되면 본 절을 갱신)

### 4.2 점프

- `Space`로 점프. 높이는 고정 (홀드해도 변하지 않음).
- 공중에서도 악셀을 사용할 수 있다.
- 공중에서도 일반 공격이 가능하다.
- **질주 점프**: 달리기 중에 점프하면 질주 상태가 유지된다. 공중 수평 속도가 질주 속도로 유지되어 **점프 거리가 보행 점프보다 길다**. 착지 후에도 홀드가 유지되면 달리기를 이어간다.

### 4.3 달리기

| 방향 | 입력 | 유지 조건 |
|------|------|-----------|
| 좌측 달리기 | `A` 2연타 후 `A` 홀드 | 홀드를 유지하는 동안 좌측 질주 |
| 우측 달리기 | `D` 2연타 후 `D` 홀드 | 홀드를 유지하는 동안 우측 질주 |

규칙:

- 2연타 판정 윈도우는 0.25s.
- 홀드를 떼면 달리기가 종료되고 기본 이동(또는 감속)으로 복귀한다.
- **달리는 동안(질주 점프의 체공 포함) 공압 게이지가 `float`로 점진 충전**된다.
- 달리기 중 방향 전환은 4.1의 관성 규칙을 따른다. 반대 방향 달리기를 시작하려면 해당 키를 다시 2연타해야 한다.
- 지상에서 시작한 달리기는 점프해도 유지된다. 공중에서 2연타로 달리기를 새로 시작할 수는 없다.

### 4.4 공격

카타나 제로 베이스의 **근접 한 방 처형**.

- 입력: 마우스 좌클릭.
- 공격 방향: **캐릭터가 마우스 커서를 바라보는 방향**.
- 판정: 공격 범위 안의 적 유닛은 즉시 사망 (특수 유닛은 타격 횟수 감소).
- 지상·공중 모두 가능. **악셀 대쉬 중 클릭은 무시**. **벽/천장 부착 중 클릭은 무시**.
- 공격 범위·후딜은 9장. 스피드가 핵심이므로 후딜은 짧게 유지한다.
- 커서 방향이 좌우를 넘으면 P의 전방(스프라이트 방향)도 커서를 따라 전환한다.

### 4.5 악셀

공압 게이지를 **1회분** 소모하고, 현재 위치에서 지정 방향으로 **짧은 고속 대쉬**를 시전한다.

공통 규칙:

- 공중에서도 사용 가능.
- 대쉬 중에는 중력을 무시한다. 궤적은 직선.
- 대쉬 중 일반 공격 입력은 무시한다.
- 연속 악셀: 악셀 직후에도 게이지가 1회분 이상 남아 있으면 바로 추가 악셀 가능.
- 대쉬 경로에 적 유닛이 있으면 **그 적 위치까지 대쉬한 뒤 해당 적은 사망**한다. (경로 관통 처형이 아니라, 최초 충돌 적에서 정지 + 처형)
- 경로에 특수 유닛이 있으면 1회 타격 후 정지. (본편, MVP 범위 밖)

#### 4.5.1 지상 악셀

지상에서는 **아래 / 좌하 / 우하를 제외**한다.

| 허용 | 상, 좌, 우, 좌상, 우상 |
|------|------------------------|
| 금지 | 하, 좌하, 우하 |

금지 방향 입력 시 악셀을 발동하지 않는다. (게이지 미소모)

#### 4.5.2 공중 악셀

8방향 모두 허용.

#### 4.5.3 천장 부착 중 악셀

천장에 붙어 있는 동안 사용 가능 방향:

| 허용 | 좌, 우, 좌하, 우하 |
|------|---------------------|

상 방향(천장 쪽) 악셀은 불가.

#### 4.5.4 벽면 부착 중 악셀

**우측 벽면에 붙은 경우** — 벽의 반대쪽(왼쪽)으로만 이탈한다.

| 허용 | 상, 좌상, 좌, 좌하, 하 |
|------|------------------------|
| 금지 | 우, 우상, 우하 (벽 쪽) |

**좌측 벽면에 붙은 경우** — 위와 좌우 대칭.

| 허용 | 상, 우상, 우, 우하, 하 |
|------|------------------------|
| 금지 | 좌, 좌상, 좌하 (벽 쪽) |

#### 4.5.5 벽 / 천장 도달 시 부착

악셀 대쉬가 **벽면 또는 천장**에 도달하면, 도달한 위치에서 **1초간 고정(부착)** 할 수 있다.

- 부착 시간: **1.0s**
- 부착 중에는 중력/관성 이동이 정지한다.
- 부착 중 일반 공격은 **불가** (클릭 무시).
- 1초가 끝나면 낙하한다.
- **1초 전 수동 이탈**: 악셀 또는 점프만 가능. 방향키만으로는 떨어지지 않는다.
- 바닥(지면)에 악셀로 도달하는 경우는 부착하지 않고 착지한다.

#### 4.5.6 악셀 역분사

악셀 대쉬 **진행 중**에 **현재 대쉬의 반대 방향**으로 재악셀하면:

- 대쉬를 즉시 중단한다.
- 소모량은 **기존 1회분의 절반** (0.5회분).
- 게이지가 0.5회분 미만이면 역분사를 할 수 없다.
- “반대 방향” 판정: **정확히 반대 1축만**. 상↔하, 좌↔우, 좌상↔우하, 우상↔좌하. 그 외 방향은 연속 악셀(1.0 소모)로 처리한다.

역분사는 **정지**가 목적이다. 반대 방향으로 새 대쉬를 시작하지 않는다.  
정지 후 남은 게이지로 다시 악셀하면 그때 새 대쉬가 나간다.

#### 4.5.7 표면 상태 × 허용 방향 요약

| 상태 | 상 | 하 | 좌 | 우 | 좌상 | 우상 | 좌하 | 우하 |
|------|:--:|:--:|:--:|:--:|:----:|:----:|:----:|:----:|
| 지상 | O | X | O | O | O | O | X | X |
| 공중 | O | O | O | O | O | O | O | O |
| 천장 부착 | X | X | O | O | X | X | O | O |
| 우측 벽 부착 | O | O | O | X | O | X | O | X |
| 좌측 벽 부착 | O | O | X | O | X | O | X | O |

### 4.6 카메라 (MVP)

- P를 **스무스 팔로우**한다. 순간 점프하지 않고, 위치 이동을 감쇠(SmoothDamp)로 따라간다.
- 수평·수직 모두 추적한다. 수평이 조금 더 빠르고, 수직은 조금 더 느리다.
- 악셀처럼 순간 이동해도 카메라가 너무 뒤처지지 않을 정도로만 부드럽게 따라온다.

## 5. 공압 게이지

자원 타입: `float`  
표시: HUD 게이지. 1칸 = 악셀 1회분.

| 이벤트 | 변화 |
|--------|------|
| 악셀 시전 | -1.0 회분 |
| 악셀 역분사 | -0.5 회분 |
| 달리기 유지 (질주 점프 체공 포함) | +0.7 / 초 |
| 적 유닛 처치 | +1.0 회분 |
| 특수 유닛 타격 | 본편 `[TBD]` |

추가 규칙:

- 시작 게이지: **2.0 회분**
- 게이지 최대치: **4.0 회분**
- 최대치를 넘지 않는다.
- **달리기가 아니면 자연 회복하지 않는다.** 대기·보행·부착 중에는 충전되지 않는다.
- 처치 충전은 공격 처치와 악셀 경로 처치 모두에 적용한다.

## 6. 유닛 공통 규칙

모든 유닛(P, 적 AI)에 적용한다.

### 6.1 사망

- **피격 1회 = 즉시 사망.**
- 공격 판정, 악셀 경로 처형, 그 외 살상 판정 모두 동일하다.

### 6.2 예외 — 특수 유닛

보스 및 스토리 특화 유닛.

- 즉사하지 않는다.
- 고유 패턴을 가지며, **일정 횟수 타격 후 사망**.
- 타격 횟수, 패턴, 무적 구간은 유닛별로 별도 정의한다. (본 문서 8장 이후에 추가)

### 6.3 P의 사망 / MVP 리셋

P 역시 1피격 즉사. 전투 사망·체크포인트는 본편 `[TBD]`.

MVP: 허수아비는 공격하지 않는다. **맵 최저점보다 5 유닛 아래로 낙하하면 시작점으로 리셋**한다. 게이지는 시작값(2.0)으로 되돌린다.

## 7. 유닛 탐색 (시야)

적 유닛이 P를 발견하는 방식.

1. 유닛이 **바라보는 방향 = 전방**.
2. 전방 **일정 거리**(`[TBD]`)를 검사한다.
3. 그 구간에서 **장애물 오브젝트가 가로막지 않으면** P가 존재한다고 판단한다.
4. P가 전방 거리 밖에 있거나, 장애물 뒤에 있으면 미발견.

구현 해석:

- 전방 레이캐스트 / 박스캐스트.
- 히트 대상이 P이면 발견.
- 히트 대상이 장애물이면 그 뒤의 P는 보이지 않음.
- 등 뒤의 P는 발견하지 않음. (방패병의 후방 감지 예외는 8.2 참고)

발견 전:

- 설정해 둔 **경로를 순회**하거나 **제자리 대기**.

발견 후:

- 해당 유닛의 전투 패턴으로 전환.

## 8. 적 유닛

### 8.1 기본 적

역할: 구간을 채우는 표준 위협. 예측 가능하지만 방심하면 죽는다.

**미발견**

- 지정 경로 순회, 또는 대기.
- 순회 중 방향이 바뀌면 아래 **방향 전환 절차**를 따른다.

**발견 후**

- 좌우로 이동하며 P를 추적한다.
- 일정 거리(`[TBD]`)에 도달하면 공격을 시도한다.
- 공격 후 다시 이동·추적을 반복한다.

**이동과 전방**

- 현재 이동 방향이 곧 전방이다.
- 시야(7장)도 이 전방을 사용한다.

**방향 전환 절차 (필수)**

즉시 턴하지 않는다.

```
이동 → 이동 중지 → 방향 전환 → 이동
```

정지 시간, 턴 애니메이션 길이는 `[TBD]`.

**공격**

- 근접. 범위 안의 P는 즉사.
- 선딜이 있어야 P가 보고 반응할 수 있다. 수치는 `[TBD]`.

### 8.2 방패병

역할: 정면 돌파를 막고, 후면 우회·악셀 역습을 요구하는 적.

**방패 (전방)**

- 전방으로 들어오는 **일반 공격**을 막는다.
- 전방으로 들어오는 **악셀**을 막는다.
- 막힌 악셀의 처리: 대쉬가 방패 위치에서 정지. `[확인 필요: 역분사와 동일하게 제자리 정지인지, 가벼운 넉백인지]`
- 막힌 일반 공격은 무효. P는 후딜만 남는다.

**후면**

- 후방으로 일반 공격 또는 악셀을 맞으면 **즉시 사망**.

**후방 인식과 방향 전환**

- P가 자신의 **후방**에 있으면, **1.0s 후** 방향을 전환한다.
- 이 1초가 암살 타이밍이다.
- 전환 시에도 기본 적과 같이 `이동 중지 → 방향 전환`을 거칠 수 있다. `[확인 필요]`

**이동**

- 기본 적과 동일한 추적/순회 골격을 쓰되, 전방을 P 쪽으로 유지하려는 성향이 더 강하다.

## 11. MVP 의사결정

목표: **P의 조작감이 완성됐는지** 검증한다.  
적 AI·시야·방패병·보스는 넣지 않는다. 적은 **허수아비**만 둔다.

| 포함 | 제외 |
|------|------|
| 이동, 점프, 달리기, 악셀, 역분사, 벽/천장 부착, 공격, 공압 게이지 | 적 AI, 시야, 방패병, 특수 유닛 |
| 테스트 룸 (바닥 / 좌우 벽 / 천장 / 단차) | 스테이지 진행, 체크포인트, 스토리 |
| 허수아비 (정지, 1히트 사망, 공격·악셀 처형 대상) | P 전투 사망 (허수아비는 공격하지 않음) |
| 게이지 HUD, 스무스 팔로우 카메라 | 사운드, 이펙트 완성도, 키 리바인드 |

### 11.1 규칙 확정

| # | 항목 | 확정 |
|---|------|------|
| 1 | 게이지 자연 회복 | **달리기만** (질주 점프 체공 포함). 대기·보행·부착은 충전 없음 |
| 2 | 시작 게이지 | **2.0 회분** |
| 3 | 게이지 최대 | **4.0 회분** |
| 4 | 부착 1초 전 수동 이탈 | **악셀 또는 점프**. 방향키만으로는 불가 |
| 5 | 달리기 중 점프 | **질주 유지**. 공중 수평 속도 = 질주 속도 → 점프 거리 증대. 홀드 유지 시 착지 후에도 질주 지속 |
| 6 | 공중 공격 | **가능** |
| 7 | 악셀 중 공격 | **무시** |
| 8 | 부착 중 공격 | **불가** (클릭 무시) |
| 9 | 역분사 판정 | **정확히 반대 1축** (상↔하, 좌↔우, 좌상↔우하, 우상↔좌하) |
| 10 | 악셀 중 중력 | **무시** (직선 대쉬) |
| 11 | 허수아비 처치 충전 | **+1.0 회분** |
| 12 | 허수아비 사망 후 | **3초 후 제자리 리스폰** |
| 13 | 맵 낙하 | **최저점 -5에서 시작점 리셋**, 게이지 2.0 복구 |
| 14 | 카메라 | **P 스무스 팔로우** (수평 0.12s / 수직 0.20s SmoothDamp) |
| 15 | 악셀↔허수아비 | 경로 첫 적에서 정지 + 처형 |
| 16 | 가변 점프 | **고정 높이** |

이미 확정되어 MVP에 그대로 가져가는 것:

- 악셀 소모 1.0, 역분사 0.5
- 벽/천장 부착 1.0s
- 지상 악셀에서 하·좌하·우하 금지
- 처치 시 게이지 +1.0
- 허수아비도 1피격 즉사
- 방향 전환은 감속 → 영점 → 재가속

### 11.2 밸런스 수치

9장 표가 단일 기준이다. MVP 출발값으로 넣었고, 플레이 후 같은 ID만 조정한다.

### 11.3 허수아비

| 항목 | 확정 |
|------|------|
| 행동 | 제자리 정지. 이동·공격·시야 없음 |
| 사망 | 공격 범위 또는 악셀 경로에 들어가면 즉시 사망 |
| 콜라이더 | P 공격·악셀이 맞을 수 있는 캡슐/박스. 높이 ≈ P와 유사 |
| 전방 | 없음. 어느 방향에서 때려도 동일 |
| 배치 | ① 평지 1기 ② 일렬 3기 (첫 적에서 악셀 정지 확인) ③ 벽 근처 ④ 공중 발판 위 |
| 처치 보상 | 공압 +1회분 |
| 리스폰 | 3.0s |

### 11.4 테스트 룸

| 공간 | 검증하는 것 |
|------|-------------|
| 긴 평지 | 보행, 달리기, 관성 턴, 게이지 충전 |
| 1칸 단차 | 보행 점프 vs 질주 점프 거리 |
| 좌·우 벽 | 악셀 부착, 악셀/점프 이탈, 부착 중 공격 무시 |
| 천장 구간 | 천장 부착, 천장에서 좌·우·좌하·우하 악셀 |
| 허수아비 평지 | 커서 방향 공격 (지상·공중) |
| 허수아비 일렬 | 악셀 경로 처형 + 첫 적에서 정지 |
| 허수아비 벽 옆 | 이탈 후 공격. 붙어 있는 동안은 때리지 못함 |
| 바닥 없는 낙하지점 | 시작점 리셋 |

### 11.5 지금 정하지 않은 것 (본편)

- 적 시야 거리, 추적, 방향 전환 정지 시간
- 방패 막힘 시 넉백 여부
- 보스 타격 횟수
- 체크포인트, 전투 사망, 무적 시간
- 히트스톱·이펙트·사운드 완성
- 타이틀, 스토리, 난이도, 키 리바인드

### 11.6 MVP 완료 조건

1. 좌우 이동 중 반대키를 눌렀을 때 감속 → 멈춤 → 재가속이 보인다.
2. `A`/`D` 2연타 홀드로 달리며 게이지가 찬다. 멈추면 충전은 멈춘다.
3. 질주 중 점프하면 더 멀리 나가고, 홀드를 유지하면 착지 후에도 달린다.
4. 지상 8방향 중 허용 방향만 악셀되고, 금지 방향은 무시된다.
5. 악셀로 벽·천장에 붙고 1초 후 떨어진다. 그 전에 악셀 또는 점프로만 이탈한다. 붙어 있는 동안 공격은 나가지 않는다.
6. 악셀 중 반대 1축 재입력 시 0.5 소모하고 그 자리에 선다. 악셀 중 클릭은 무시된다.
7. 시작 게이지 2, 최대 4. 남아 있으면 연속 악셀, 부족하면 무시.
8. 마우스 클릭이 커서 방향으로 나가고 (지상·공중), 범위 안 허수아비가 죽는다.
9. 악셀 경로의 첫 허수아비만 죽고, P는 그 위치에서 멈춘다. 처치 시 게이지 +1.
10. 카메라가 P를 끊김 없이 스무스하게 따라간다.

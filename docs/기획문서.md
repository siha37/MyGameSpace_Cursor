## 1. 개요

| 항목 | 내용 |
|------|------|
| 플랫폼 | Windows |
| 엔진 | Unity |
| 장르 | 2D 횡스크롤 스타일리시 액션 |
| 레퍼런스 | 카타나 제로 (Katana ZERO) |
| 시점 | 사이드 뷰, 횡 스크롤 |
| 핵심 톤 | 빠르고, 심플하고, 한 번의 실수가 곧 죽음 |

한 판의 전투는 **짧은 판단 → 즉각 처형 → 다음 이동**으로 끝난다.  
복잡한 콤보나 HP 막기보다, **위치·방향·타이밍**만으로 승부가 갈리게 한다.

## 2. 코어 디자인

### 2.1 디자인 포인트

- **스피드**: 이동, 달리기, 악셀이 즉각적으로 반응한다.
- **심플함**: 입력은 적고, 처형은 악셀 한 가지다. 한 대면 죽는다.
- **스타일리시**: 8방향 악셀 궤적, 방향 전환의 관성, 벽/천장 고정이 리듬을 만든다.

### 2.2 플레이 루프 (한 구간)

```
진입 → 경로 파악 → 접근/유인 → 악셀로 처형 → 공압 회복 → 다음 구간
```

실패 조건은 단순하다. 피격 1회 = 사망 (특수 유닛 제외).

### 2.3 용어

| 용어 | 정의 |
|------|------|
| P | 플레이어블 캐릭터 |
| 유닛 | P와 적군 AI를 포함한 모든 캐릭터 |
| 특수 유닛 | 보스/스토리 특화 유닛. 즉사 규칙의 예외 |
| 전방 | 해당 유닛이 현재 바라보는 방향 |
| 악셀 | 공압 게이지를 소모하는 8방향 대쉬. 유일한 공격 수단 |
| 공압 게이지 | 악셀 자원. `float`로 점진 충전 |
| 악셀 역분사 | 악셀 도중 반대 방향 재악셀로 대쉬를 끊는 기술 |
| 부착 | 악셀로 벽면/천장에 도달했을 때 일정 시간 고정된 상태 |

## 3. 조작

플랫폼: **Windows / 키보드 + 마우스**

| 행동 | 입력 | 비고 |
|------|------|------|
| 이동 | `A` `D` | **질주**. 속도·게이지 충전은 기존 달리기와 동일. 관성 적용. `W`/`S`는 지상 이동에 쓰지 않음 |
| 점프 | `Space` | |
| 악셀 | `Shift` + 방향키/`WASD` | **8방향**. 상태별 금지 방향이면 미소모 |

### 3.1 악셀 조준

마우스 조준을 쓰지 않는다. `Shift`와 함께 누른 **8방향**으로 직선 대쉬한다.

1. 방향키 또는 `WASD`로 8방향 중 하나를 유지한다.
2. `Shift`를 **탭**한다.
3. 현재 상태의 금지 방향이면 시전하지 않는다. (게이지 미소모)
4. 허용되면 그 8방향 직선으로 대쉬한다.

방향 입력이 없으면 시전하지 않는다.

## 4. 플레이어 시스템

### 4.1 이동

일반적인 2D 횡스크롤과 같이 `A`/`D`로 좌우 이동한다.  
기본 이동이 **질주**다. 예전 보행 속도는 쓰지 않는다. 속도·공압 충전은 기존 달리기와 같다. `A` 또는 `D`를 누르면 그 방향으로 질주한다. 2연타는 없다.

**방향 전환 관성 (필수)**  
우측 이동 중 좌측으로 순간 전환할 때(또는 그 반대) 속도가 즉시 반전되지 않는다.

```
가속 중 → 감속 → 영점 속도(0) → 반대 방향 가속
```

- 감속 구간과 재가속 구간이 체감되어야 한다.
- 짧은 거리의 미세 조작과, 전력 질주 중 급선회의 무게감이 구분되어야 한다.
- 구체 수치는 9장. 카타나 제로보다 약간 묵직하되, 답답하지 않은 수준을 목표로 한다.

`W`/`S`는 지상 기본 이동의 상하 보행에 사용하지 않는다. 악셀 8방향에만 쓴다.

### 4.2 점프

- `Space`로 점프. 높이는 고정 (홀드해도 변하지 않음).
- 공중에서도 악셀을 사용할 수 있다.
- **질주 점프**: 이동 중에 점프하면 질주가 유지된다. 공중 수평 속도가 질주 속도로 유지되어 점프 거리가 길다. 착지 후에도 홀드가 유지되면 질주를 이어간다.

### 4.3 달리기 (기본 이동)

`A`/`D` 홀드가 곧 질주다.

| 방향 | 입력 | 유지 조건 |
|------|------|-----------|
| 좌측 질주 | `A` 홀드 | 키를 누르는 동안 좌측 질주 |
| 우측 질주 | `D` 홀드 | 키를 누르는 동안 우측 질주 |

규칙:

- 2연타는 없다. 이동키가 트리거다.
- 홀드를 떼면 질주가 종료되고 감속으로 멈춘다.
- **질주하는 동안(질주 점프의 체공 포함) 공압 게이지가 `float`로 점진 충전**된다.
- 질주 중 방향 전환은 4.1의 관성 규칙을 따른다.
- 지상에서 시작한 질주는 점프해도 유지된다.

### 4.4 공격 (제거)

MVP에서 **일반 근접 공격은 존재하지 않는다.**  
처형은 **악셀 경로 충돌만**으로 한다. 마우스 좌클릭은 할당하지 않는다.

### 4.5 악셀

공압 게이지를 **1회분** 소모하고, **8방향**으로 **짧은 고속 대쉬**를 시전한다. 이것이 유일한 공격이다.

공통 규칙:

- 공중에서도 사용 가능.
- 대쉬 중에는 중력을 무시한다. 궤적은 직선.
- 대쉬 중에는 악셀을 재시전할 수 없다. (역분사는 예외)
- 악셀 가속이 완전히 끝난 뒤 **0.1s**가 지나야 다시 시전 가능. 게이지가 1회분 이상 남아 있어야 한다.
- 대쉬 경로에 적 유닛이 있으면 **첫 번째 적 앞에서 대쉬가 중단**되고 해당 적은 사망한다. 뒤의 적은 맞지 않는다.
- **예외 — 전방 대치**: P와 허수아비가 서로를 바라보고, P가 그 전방으로 악셀하면 처형하지 않는다. 악셀은 **즉시 취소**되고 P는 악셀 반대 방향으로 넉백된다. 넉백 후 **0.5s 조작 불가**. 게이지는 이미 소모된다. 후면·측후방에서 들어오면 기존처럼 처형한다.
- 경로에 특수 유닛이 있으면 1회 타격 후 정지. (본편, MVP 범위 밖)
- 악셀 좌우 방향에 따라 P의 전방(스프라이트)을 갱신한다.
- **벽/천장에 닿지 못하고** 악셀 시간이 끝나면, 속도를 0으로 끊지 않는다. 악셀 속도의 **20%**로 낮춘 뒤 중력을 다시 받고 추락한다. (악셀 100이면 낙하 진입 속도 20) 착지·처형·부착·역분사는 기존처럼 정지.

#### 4.5.1 지상 악셀

하·좌하·우하 금지. 게이지 미소모.  
좌·좌상·상·우상·우는 허용.

#### 4.5.2 공중 악셀

8방향 전부 허용.

#### 4.5.3 천장 부착 중 악셀

방향키는 쓰지 않는다. **Shift만** 누르면 천장에서 이탈한다. 수평(좌·우) 악셀은 불가.

이탈 방향은 천장에 붙은 악셀에 따라 고정된다.

- **우상** 악셀로 천장 부착 → Shift = **우하**
- **좌상** 악셀로 천장 부착 → Shift = **좌하**
- **수직 상승** 악셀로 천장 부착 → Shift = **악셀 직전 이동 방향 + 하단** (우로 가다 위로 붙었으면 우하, 좌면 좌하)

상·좌상·우상·좌·우 금지.

#### 4.5.4 벽면 부착 중 악셀

벽 속(표면 안쪽) 방향 금지. 법선과 내적이 **-0.1 미만**이면 금지.

- 우측 벽 (법선 ≈ 왼쪽): 왼쪽 반구로만 이탈.
- 좌측 벽 (법선 ≈ 오른쪽): 오른쪽 반구로만 이탈.

#### 4.5.5 벽 / 천장 도달 시 부착

악셀 대쉬가 **벽면 또는 천장**에 도달한 경우에만, 도달한 위치에서 **1초간 고정(부착)** 할 수 있다.

- 부착은 **악셀로 표면에 도달했을 때만** 발동한다. 점프·이동으로 벽에 닿으면 부착하지 않고 즉시 미끄러진다.
- 좌상·우상 악셀이 천장에 닿아도 **닿은 그 좌표에 고정**한다. 천장 면을 따라 미끄러지지 않는다.
- 부착 시간: **1.0s**
- 부착 중에는 중력/관성 이동이 정지한다.
- 1초가 끝나면 낙하한다.
- **1초 전 수동 이탈**: 악셀 또는 점프만 가능. 방향키만으로는 떨어지지 않는다.
- 벽에서 악셀로 이탈할 때, 붙어 있던 벽은 무시하고 8방향으로 대쉬한다.
- 바닥(지면)에 **하향** 악셀로 도달하는 경우는 부착하지 않고 착지한다.
- 지상에서 좌·우 악셀은 발밑 지면을 도달로 보지 않는다. 바닥 때문에 악셀이 끊기지 않는다.

맵의 천장 높이는 **기존 실내 높이(4.6)의 1.2배 = 5.52**다. 천장 하면 ≈ 4.02. 지상 상향 악셀(`AX-DIST` 6.0)로 도달 가능하다.

#### 4.5.5.1 의도하지 않은 벽 부착 방지

물리 엔진 마찰 때문에 점프·이동만으로 벽에 달라붙으면 안 된다.

- P와 Ground의 **마찰 = 0**.
- `WallStick` / `CeilingStick`이 **아닐 때** 수직 벽 접촉이 있으면, 벽으로 파고드는 속도 성분을 제거하고 법선 쪽으로 미세 분리한다.
- 1초 고정은 **악셀이 벽/천장에 도달한 경우만**.

#### 4.5.6 악셀 역분사

악셀 대쉬 **진행 중**에 **현재 대쉬의 반대 방향**으로 재악셀하면:

- 대쉬를 즉시 중단한다.
- 소모량은 **기존 1회분의 절반** (0.5회분).
- 게이지가 0.5회분 미만이면 역분사를 할 수 없다.
- “반대 방향” 판정: 현재 대쉬와 **반대 8방향**. 내적 **< -0.9**. 대쉬 중 `Shift` + 반대키.

역분사는 **정지**가 목적이다. 반대 방향으로 새 대쉬를 시작하지 않는다.  
정지 후 가속이 끝난 것으로 보고 **0.1s** 뒤에, 남은 게이지로 다시 악셀할 수 있다.

#### 4.5.7 표면 상태 × 허용 8방향

| 상태 | 허용 | 금지 |
|------|------|------|
| 지상 | 좌, 좌상, 상, 우상, 우 | 하, 좌하, 우하 |
| 공중 | 8방향 | 없음 |
| 천장 부착 | Shift만. 우상→우하, 좌상→좌하, 수직상승→이동방향+하 | 상, 좌상, 우상, **좌, 우** |
| 벽 부착 | 벽 바깥 반구에 해당하는 8방향 | 벽 속 |

### 4.6 카메라 (MVP)

- P를 **스무스 팔로우**한다. 순간 점프하지 않고, 위치 이동을 감쇠(SmoothDamp)로 따라간다.
- 수평·수직 모두 추적한다. 수평이 조금 더 빠르고, 수직은 조금 더 느리다.
- 악셀처럼 순간 이동해도 카메라가 너무 뒤처지지 않을 정도로만 부드럽게 따라온다.

### 4.7 HUD

- 좌상단: 공압 게이지
- **우측 상단: `HELP` 버튼.** 누르면 조작법 팝업. Esc / 닫기 / 바깥 클릭으로 닫는다. 열려 있는 동안 게임은 일시정지되고 조작은 막힌다.

## 5. 공압 게이지

자원 타입: `float`  
표시: HUD 게이지. 1칸 = 악셀 1회분.

| 이벤트 | 변화 |
|--------|------|
| 악셀 시전 | -1.0 회분 |
| 악셀 역분사 | -0.5 회분 |
| 달리기 유지 (질주 점프 체공 포함) | +0.7 / 초 |
| 적 유닛 처치 | +1.0 회분 |
| 특수 유닛 타격 | 본편 `[TBD]` |

추가 규칙:

- 시작 게이지: **4.0 회분**
- 게이지 최대치: **5.0 회분**
- 최대치를 넘지 않는다.
- **이동(질주)가 아니면 자연 회복하지 않는다.** 대기·부착 중에는 충전되지 않는다.
- **악셀이 시작되면 질주 충전은 즉시 중지**한다. 악셀·역분사·부착 중에는 충전하지 않는다. 악셀이 끝난 뒤 이동키를 누르고 있으면 다시 충전한다.
- 처치 충전은 **악셀 경로 처치**에만 적용한다.

## 6. 유닛 공통 규칙

모든 유닛(P, 적 AI)에 적용한다.

### 6.1 사망

- **피격 1회 = 즉시 사망.**
- MVP에서 P의 살상 수단은 악셀 경로 처형뿐이다.

### 6.2 예외 — 특수 유닛

보스 및 스토리 특화 유닛.

- 즉사하지 않는다.
- 고유 패턴을 가지며, **일정 횟수 타격 후 사망**.
- 타격 횟수, 패턴, 무적 구간은 유닛별로 별도 정의한다. (본 문서 8장 이후에 추가)

### 6.3 P의 사망 / MVP 리셋

P 역시 1피격 즉사. 전투 사망·체크포인트는 본편 `[TBD]`.

## 7. 유닛 탐색 (시야)

적 유닛이 P를 발견하는 방식.

1. 유닛이 **바라보는 방향 = 전방**.
2. 전방 **일정 거리**(`[TBD]`)를 검사한다.
3. 그 구간에서 **장애물 오브젝트가 가로막지 않으면** P가 존재한다고 판단한다.
4. P가 전방 거리 밖에 있거나, 장애물 뒤에 있으면 미발견.

구현 해석:

- 전방 레이캐스트 / 박스캐스트.
- 히트 대상이 P이면 발견.
- 히트 대상이 장애물이면 그 뒤의 P는 보이지 않음.
- 등 뒤의 P는 발견하지 않음. (방패병의 후방 감지 예외는 8.2 참고)

발견 전:

- 설정해 둔 **경로를 순회**하거나 **제자리 대기**.

발견 후:

- 해당 유닛의 전투 패턴으로 전환.

## 8. 적 유닛

### 8.1 기본 적

역할: 구간을 채우는 표준 위협. 예측 가능하지만 방심하면 죽는다.

**미발견**

- 지정 경로 순회, 또는 대기.
- 순회 중 방향이 바뀌면 아래 **방향 전환 절차**를 따른다.

**발견 후**

- 좌우로 이동하며 P를 추적한다.
- 일정 거리(`[TBD]`)에 도달하면 공격을 시도한다.
- 공격 후 다시 이동·추적을 반복한다.

**이동과 전방**

- 현재 이동 방향이 곧 전방이다.
- 시야(7장)도 이 전방을 사용한다.

**방향 전환 절차 (필수)**

즉시 턴하지 않는다.

```
이동 → 이동 중지 → 방향 전환 → 이동
```

정지 시간, 턴 애니메이션 길이는 `[TBD]`.  
이 경직 구간이 P가 파고들 수 있는 약점이다.

**공격**

- 근접. 범위 안의 P는 즉사.
- 선딜이 있어야 P가 보고 반응할 수 있다. 수치는 `[TBD]`.

### 8.2 방패병

역할: 정면 돌파를 막고, 후면 우회·악셀 역습을 요구하는 적.

**방패 (전방)**

- 전방으로 들어오는 **악셀**을 막는다.
- 막힌 악셀의 처리: 대쉬가 방패 위치에서 정지. `[확인 필요: 역분사와 동일하게 제자리 정지인지, 가벼운 넉백인지]`

**후면**

- 후방으로 악셀을 맞으면 **즉시 사망**.

**후방 인식과 방향 전환**

- P가 자신의 **후방**에 있으면, **1.0s 후** 방향을 전환한다.
- 이 1초가 암살 타이밍이다.
- 전환 시에도 기본 적과 같이 `이동 중지 → 방향 전환`을 거칠 수 있다. `[확인 필요]`

**이동**

- 기본 적과 동일한 추적/순회 골격을 쓰되, 전방을 P 쪽으로 유지하려는 성향이 더 강하다.

### 11.6 MVP 완료 조건

1. 좌우 이동 중 반대키를 눌렀을 때 감속 → 멈춤 → 재가속이 보인다.
2. `A`/`D`를 누르면 질주하며 게이지가 찬다. 멈추면 충전은 멈춘다.
3. 질주 중 점프하면 더 멀리 나가고, 홀드를 유지하면 착지 후에도 달린다.
4. `Shift` + 방향키로 8방향 악셀된다. 지상 하/좌하/우하·벽 속·천장 쪽은 무시된다.
5. 악셀로 벽·천장에 붙고 1초 후 떨어진다. 점프만으로 벽에 닿으면 미끄러진다. 그 전에 악셀 또는 점프로 이탈한다. 천장에는 지상 상향 악셀로 닿는다.
5-1. 악셀이 벽/천장에 닿지 못하면 악셀 속도의 20%로 낮춘 뒤 떨어진다.
6. 악셀 중 반대 8방향으로 `Shift` 재탭 시 0.5 소모하고 그 자리에 선다.
7. 시작 게이지 4, 최대 5. 악셀 가속이 끝난 뒤 0.1s가 지나야 재시전. 게이지 부족 시 무시.
8. 일반 근접 공격은 없다. 허수아비는 악셀로만 죽는다.
9. 악셀 경로의 첫 허수아비 앞에서 멈추고, 그 허수아비만 죽는다. 처치 시 게이지 +1.
10. 카메라가 P를 끊김 없이 스무스하게 따라간다.
11. 허수아비는 일정 거리 안이 아니면 대기하고, 들어오면 지상에서만 P를 추적한다. 점프하지 않고, 낭떠러지에서 멈춘다. 방향 전환 시 0.8초 정지한 뒤 노란 전방이 바뀐다. 죽으면 다시 나오지 않는다.
12. 허수아비 전방(노란 테두리)으로 마주보고 악셀하면 취소되고 반대 넉백 후 0.5초 조작할 수 없다. 뒤로 들어가면 처형된다.

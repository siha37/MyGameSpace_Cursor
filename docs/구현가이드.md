# MVP 구현 가이드

## 프로젝트 구조

```
cylinder/Assets/
├── Scripts/
│   ├── Core/           # 핵심 시스템
│   │   ├── GameConstants.cs      # 게임 상수
│   │   ├── PressureGauge.cs      # 공압 게이지
│   │   ├── InputHelper.cs        # WASD / 8방향 악셀
│   │   └── IDamageable.cs        # 피해 인터페이스
│   ├── Player/         # 플레이어 시스템
│   │   ├── PlayerController.cs   # 메인 컨트롤러
│   │   ├── PlayerState.cs        # 상태 열거형
│   │   ├── PlayerMovement.cs     # 이동 시스템
│   │   └── PlayerAccel.cs        # 악셀 시스템 (유일한 공격)
│   ├── Camera/         # 카메라
│   │   └── SmoothFollowCamera.cs # 스무스 팔로우
│   ├── Enemy/          # 적
│   │   └── Dummy.cs              # 허수아비
│   └── UI/             # UI
│       └── GaugeUI.cs            # 게이지 UI
├── Scenes/
│   └── TestRoom.unity            # 테스트 룸
└── ...
```

## Unity 설정 필요 사항

### 레이어 (Layers)
1. **Ground** (Layer 6) - 지형, 벽, 천장
2. **Enemy** (Layer 7) - 적 유닛
3. **Player** (Layer 8) - 플레이어

### 태그 (Tags)
- **Player** - 플레이어 오브젝트
- **Enemy** - 적 오브젝트

### Physics 2D 설정
- Project Settings > Physics 2D > Gravity Y: -20 (권장)
- Layer Collision Matrix: Player × Enemy 해제
- `Assets/Physics/NoFriction.physicsMaterial2D` 를 Player와 Ground에 적용

## 씬 구성

### TestRoom 씬 구조

#### 1. Main Camera
- 컴포넌트: `SmoothFollowCamera`
- Target: Player

#### 2. Player
- 컴포넌트:
  - `PlayerController`
  - `Rigidbody2D` (Gravity Scale: 1, Constraints: Freeze Rotation Z)
  - `CapsuleCollider2D` (Size: 1.0 x 1.2, 비율 1:1.2)
  - `PressureGauge`
  - Physics Material 2D 마찰 0
- Layer: Player
- Tag: Player

#### 3. RespawnPoint (Empty GameObject)
- Position: 시작 위치
- PlayerController의 Respawn Point로 설정

#### 4. Ground (플랫폼들)
- 컴포넌트:
  - `BoxCollider2D`
  - Physics Material 2D 마찰 0
- Layer: Ground

#### 5. Walls (좌우 벽)
- 컴포넌트:
  - `BoxCollider2D`
  - Physics Material 2D 마찰 0
- Layer: Ground

#### 6. Ceiling (천장)
- 컴포넌트:
  - `BoxCollider2D`
  - Physics Material 2D 마찰 0
- Layer: Ground

#### 7. Dummy (허수아비들)
- 컴포넌트:
  - `Dummy`
  - `Rigidbody2D` (Gravity Scale 1, Freeze Rotation Z)
  - `BoxCollider2D` (Size: 1.0 x 1.2)
- Layer: Enemy
- Tag: Enemy
- P와 물리 충돌하지 않음 (통과). 악셀 박스캐스트는 적중
- 지상에서만 P를 좌우 추적 (속도 5). **거리 8 밖이면 대기**, 안으로 들어오면 추적. 거리 10을 넘으면 다시 대기. 점프 없음. 낭떠러지에서 정지
- 방향 전환 시 0.8s 정지(기존 전방 유지). 끝나면 전방(+X/-X)과 노란 표기만 스냅 후 이동. 오브젝트는 회전하지 않음
- 전방 = 이동 방향. 자식 `FrontMarker` 노란 스프라이트로 전방 테두리 표시
- 마주보고 전방 악셀: 취소 + 반대 넉백 + 0.5s 조작 불가. 후면 악셀은 처형
- **사망 후 재생성 없음**
- 배치:
  - 바닥 유지: Dummy_2 `(-40, -1.5)` / Dummy_3 `(-24, -1.5)` / Dummy_4 `(씬에 저장된 위치)`
  - Floor_L1 Dummy_5 `(18, 2.7)`
  - Floor_L2 Dummy_6 `(-16, 6.9)`
  - Floor_L3 Dummy_7 `(8, 11.1)`
  - Floor_L4 Dummy_8 `(-8, 15.3)`

#### 8. Canvas (UI)
- Render Mode: Screen Space - Overlay
- 자식:
  - **GaugePanel**
    - 컴포넌트: `GaugeUI`
    - 자식:
      - **Background** (Image)
      - **Fill** (Image, Fill Amount: 1)
      - **Text** (Text: "4.0 / 5.0")
  - **HelpButton** (우측 상단 HELP)
  - **HelpPopup** (조작법 팝업). Canvas에 `HelpUI`

## 테스트 체크리스트

### 이동 시스템
- [ ] A/D 키로 좌우 이동
- [ ] 방향 전환 시 감속 → 정지 → 재가속 관성
- [ ] A/D 홀드로 질주 (속도 11, 홀드 유지)
- [ ] 질주 중 게이지 충전 (0.7/초)
- [ ] 달리기 중 점프 시 더 먼 거리
- [ ] Space로 점프 (고정 높이 2.2)

### 악셀 시스템
- [ ] Shift + 방향키/WASD로 8방향 악셀
- [ ] 지상에서 하/좌하/우하 악셀 금지 (게이지 미소모)
- [ ] 공중에서 전 방향 가능
- [ ] 천장 부착 중 Shift만으로 이탈 (우상→우하, 좌상→좌하, 수직상승→이동방향+하). 수평 악셀 불가
- [ ] 벽 부착 중 벽 속 방향 금지
- [ ] 악셀로 벽/천장 도달 시 1초 부착
- [ ] 점프/이동으로 벽에 닿으면 미끄러짐 (마찰 0)
- [ ] 부착 중 1초 후 자동 낙하
- [ ] 부착 중 악셀/점프로 이탈 가능
- [ ] 악셀 중 반대 8방향으로 역분사 (0.5 소모)
- [ ] 게이지 부족 시 악셀 불가
- [ ] 악셀 종료 후 0.1s가 지나야 재시전
- [ ] 지상에서 위로 악셀하면 천장에 닿는다
- [ ] 벽/천장에 못 닿으면 악셀 속도의 20%로 낮춘 뒤 낙하

### 악셀 경로 처치 (유일한 공격)
- [ ] 일반 근접 공격 없음 (좌클릭 미할당)
- [ ] 악셀 경로의 첫 허수아비에서 정지
- [ ] 해당 허수아비 처치
- [ ] 게이지 +1.0 획득

### 허수아비
- [ ] 악셀 경로에 맞으면 즉시 사망
- [ ] 죽으면 다시 생성되지 않음
- [ ] 거리 8 밖에서는 대기. 안으로 들어오면 지상 추적
- [ ] 방향 전환 시 0.8초 정지 후 노란 전방이 반대쪽으로 이동. 몸통은 회전하지 않음
- [ ] 낭떠러지 앞에서 멈춤
- [ ] 전방 노란 테두리로 이동 방향을 알 수 있음
- [ ] 마주보고 전방 악셀 시 취소·넉백·0.5s 경직
- [ ] 후면 악셀은 처형

### 게이지
- [ ] 시작 게이지 4.0
- [ ] 최대 게이지 5.0
- [ ] UI에 현재/최대 표시

### Help
- [ ] 우측 상단 HELP 버튼
- [ ] 클릭 시 조작법 팝업, 게임 일시정지
- [ ] Esc / 닫기 / 바깥 클릭으로 닫힘

### 카메라
- [ ] 플레이어를 부드럽게 추적
- [ ] 수평이 수직보다 빠름

### 리스폰
- [ ] 맵 최저점 -5 낙하 시 시작점 리셋
- [ ] 게이지 4.0 복구

## 디버깅 팁

### 게이지가 충전되지 않을 때
- A/D 홀드 확인 (기본 이동 = 질주)

### 악셀이 안 나갈 때
- 게이지 확인
- 현재 상태에서 해당 방향 허용 여부 확인
- 콘솔 로그 확인

### 악셀이 허수아비에 안 맞을 때
- Enemy 레이어 확인
- IDamageable 인터페이스 구현 확인
- 8방향 입력 기즈모(청록) 확인

### 부착이 안 될 때
- Ground 레이어 확인
- 표면 Normal 벡터 확인

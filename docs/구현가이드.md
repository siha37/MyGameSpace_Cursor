# MVP 구현 가이드

## 프로젝트 구조

```
cylinder/Assets/
├── Scripts/
│   ├── Core/           # 핵심 시스템
│   │   ├── GameConstants.cs      # 게임 상수
│   │   ├── PressureGauge.cs      # 공압 게이지
│   │   └── IDamageable.cs        # 피해 인터페이스
│   ├── Player/         # 플레이어 시스템
│   │   ├── PlayerController.cs   # 메인 컨트롤러
│   │   ├── PlayerState.cs        # 상태 열거형
│   │   ├── PlayerMovement.cs     # 이동 시스템
│   │   ├── PlayerAccel.cs        # 악셀 시스템
│   │   └── PlayerAttack.cs       # 공격 시스템
│   ├── Camera/         # 카메라
│   │   └── SmoothFollowCamera.cs # 스무스 팔로우
│   ├── Enemy/          # 적
│   │   └── Dummy.cs              # 허수아비
│   └── UI/             # UI
│       └── GaugeUI.cs            # 게이지 UI
├── Scenes/
│   └── TestRoom.unity            # 테스트 룸
└── ...
```

## Unity 설정 필요 사항

### 레이어 (Layers)
1. **Ground** (Layer 6) - 지형, 벽, 천장
2. **Enemy** (Layer 7) - 적 유닛
3. **Player** (Layer 8) - 플레이어

### 태그 (Tags)
- **Player** - 플레이어 오브젝트
- **Enemy** - 적 오브젝트

### Physics 2D 설정
- Project Settings > Physics 2D > Gravity Y: -20 (권장)

## 씬 구성

### TestRoom 씬 구조

#### 1. Main Camera
- 컴포넌트: `SmoothFollowCamera`
- Target: Player

#### 2. Player
- 컴포넌트:
  - `PlayerController`
  - `Rigidbody2D` (Gravity Scale: 1, Constraints: Freeze Rotation Z)
  - `CapsuleCollider2D` (Size: 0.5 x 1.8)
  - `PressureGauge`
- Layer: Player
- Tag: Player

#### 3. RespawnPoint (Empty GameObject)
- Position: 시작 위치
- PlayerController의 Respawn Point로 설정

#### 4. Ground (플랫폼들)
- 컴포넌트:
  - `BoxCollider2D`
- Layer: Ground

#### 5. Walls (좌우 벽)
- 컴포넌트:
  - `BoxCollider2D`
- Layer: Ground

#### 6. Ceiling (천장)
- 컴포넌트:
  - `BoxCollider2D`
- Layer: Ground

#### 7. Dummy (허수아비들)
- 컴포넌트:
  - `Dummy`
  - `BoxCollider2D` (Size: 0.5 x 1.8)
- Layer: Enemy
- Tag: Enemy
- 배치:
  - 평지 1기
  - 일렬 3기 (악셀 경로 처치 테스트)
  - 벽 근처 1기
  - 공중 발판 위 1기

#### 8. Canvas (UI)
- Render Mode: Screen Space - Overlay
- 자식:
  - **GaugePanel**
    - 컴포넌트: `GaugeUI`
    - 자식:
      - **Background** (Image)
      - **Fill** (Image, Fill Amount: 1)
      - **Text** (Text: "2.0 / 4.0")

## 테스트 체크리스트

### 이동 시스템
- [ ] A/D 키로 좌우 이동
- [ ] 방향 전환 시 감속 → 정지 → 재가속 관성
- [ ] A/D 2연타로 달리기 (홀드 유지)
- [ ] 달리기 중 게이지 충전 (0.7/초)
- [ ] 달리기 중 점프 시 더 먼 거리
- [ ] Space로 점프 (고정 높이 2.2)

### 악셀 시스템
- [ ] Shift + 방향키로 8방향 악셀
- [ ] 지상에서 하/좌하/우하 악셀 금지
- [ ] 공중에서 8방향 모두 가능
- [ ] 악셀로 벽/천장 도달 시 1초 부착
- [ ] 부착 중 1초 후 자동 낙하
- [ ] 부착 중 악셀/점프로 이탈 가능
- [ ] 악셀 중 반대 방향으로 역분사 (0.5 소모)
- [ ] 게이지 부족 시 악셀 불가
- [ ] 연속 악셀 가능

### 공격 시스템
- [ ] 마우스 좌클릭으로 커서 방향 공격
- [ ] 공격 범위 안의 허수아비 처치
- [ ] 처치 시 게이지 +1.0
- [ ] 지상/공중 모두 공격 가능
- [ ] 악셀 중 공격 불가
- [ ] 부착 중 공격 불가

### 악셀 경로 처치
- [ ] 악셀 경로의 첫 허수아비에서 정지
- [ ] 해당 허수아비 처치
- [ ] 게이지 +1.0 획득

### 허수아비
- [ ] 공격/악셀 경로에 맞으면 즉시 사망
- [ ] 3초 후 제자리 리스폰

### 게이지
- [ ] 시작 게이지 2.0
- [ ] 최대 게이지 4.0
- [ ] UI에 현재/최대 표시

### 카메라
- [ ] 플레이어를 부드럽게 추적
- [ ] 수평이 수직보다 빠름

### 리스폰
- [ ] 맵 최저점 -5 낙하 시 시작점 리셋
- [ ] 게이지 2.0 복구

## 디버깅 팁

### 게이지가 충전되지 않을 때
- 달리기 2연타 확인 (0.25초 내)
- 홀드 유지 확인

### 악셀이 안 나갈 때
- 게이지 확인
- 현재 상태에서 해당 방향 허용 여부 확인
- 콘솔 로그 확인

### 공격이 안 맞을 때
- Enemy 레이어 확인
- IDamageable 인터페이스 구현 확인
- 공격 범위 확인 (Gizmos 그리기 권장)

### 부착이 안 될 때
- Ground 레이어 확인
- 표면 Normal 벡터 확인

🎯 2. 코어 디자인

⚡ 디자인 포인트

🚀 스피드
이동, 달리기, 악셀, 공격이 모두 즉각적으로 반응
✨ 심플함
입력은 적고, 규칙은 명확. 한 대면 죽음
🎨 스타일리시
악셀 궤적, 관성, 벽 부착이 시각적 리듬 생성

🔄 플레이 루프

진입 → 경로 파악 → 접근/유인 → 처형 → 공압 회복 → 다음 구간
⚠️ 실패 조건: 피격 1회 = 사망 (특수 유닛 제외)

📚 용어 정의

용어 정의
P 플레이어블 캐릭터
악셀 ⚡ 공압 게이지를 소모하는 8방향 대쉬
공압 게이지 악셀 자원. float로 점진 충전
역분사 악셀 중 반대 방향 입력으로 대쉬 중단
부착 악셀로 벽/천장 도달 시 1초간 고정

👤 4. 플레이어 시스템

🚶 4.1 이동 & 관성

✨ 방향 전환 관성 (필수 특징)
우측 이동 중 좌측 전환 시 속도가 즉시 반전되지 않습니다.
가속 중 → 감속 → 영점(0) → 반대 방향 가속
카타나 제로보다 약간 묵직하되, 답답하지 않은 수준

🦘 4.2 점프

  • 고정 높이 (홀드 시간 무관)
  • 공중에서 악셀 사용 가능
  • 공중 공격 가능
  • 질주 점프: 달리기 중 점프 시 거리 증가

🏃 4.3 달리기

방향 입력 효과
← 좌측 질주 A 2연타 + 홀드 ⚡ 공압 게이지 충전
(0.7 / 초)
→ 우측 질주 D 2연타 + 홀드
⏱️ 2연타 판정: 0.25초 이내
🔄 유지 조건: 홀드 유지 (떼면 종료)
✈️ 공중 유지: 질주 점프 중에도 게이지 충전

⚔️ 4.4 공격

🎯 근접 한 방 처형 (카타나 제로 스타일)

• 입력: 🖱️ 마우스 좌클릭
• 방향: 마우스 커서 위치
• 판정: 범위 안 적 즉시 사망
• 가능: 지상·공중
• 불가: 악셀 중, 벽/천장 부착 중

⚡ 4.5 악셀 (핵심 시스템)

공통 규칙
• 공압 게이지 1.0 소모
• 8방향 고속 직선 대쉬
• 중력 무시, 공격 불가
• 경로상 적 처치 (첫 적에서 정지)
• 연속 악셀 가능 (게이지 충분 시)

🎯 부착 시스템

악셀로 벽/천장 도달 시
• ⏱️ 부착 시간: 1.0초
• 🚫 중력/관성 정지, 공격 불가
• ⏰ 1초 후 자동 낙하
• 🔓 수동 이탈: 악셀 또는 점프만 가능
• 💡 바닥 도달 시 부착 없이 착지

🔄 역분사

악셀 진행 중 반대 방향 재입력

• 💨 즉시 중단 (정지)
• ⚡ 소모량: 0.5 회분
• 🎯 판정: 정확히 반대 1축 (상↔하, 좌↔우, 좌상↔우하, 우상↔좌하)
• ⚠️ 게이지 0.5 미만 시 불가

⚡ 5. 공압 게이지

자원 타입: float
표시: HUD 게이지 (1칸 = 악셀 1회분)
이벤트 변화
⚡ 악셀 시전 -1.0 회분
🔄 역분사 -0.5 회분
🏃 달리기 유지 +0.7 / 초
💀 적 처치 +1.0 회분
게이지 수치
• 🎬 시작: 2.0 회분
• 🔝 최대: 4.0 회분
• 📈 충전: 달리기만 가능 (대기·보행 시 충전 없음)
• ✅ 처치 충전: 공격·악셀 경로 처치 모두 적용

🎯 허수아비 사양

항목 내용
🤖 행동 제자리 정지 (이동·공격·시야 없음)
💀 사망 공격 범위 또는 악셀 경로 진입 시 즉시 사망
🎁 보상 공압 게이지 +1.0 회분
🔄 리스폰 3.0초 후 제자리 재생성
📍 배치 ① 평지 1기
② 일렬 3기 (악셀 경로 테스트)
③ 벽 근처 1기
④ 공중 발판 위 1기

✅ MVP 완료 조건

  • 좌우 이동 중 반대키 입력 시 감속 → 멈춤 → 재가속 체감
  • A/D 2연타 홀드로 달리며 게이지 충전 확인
  • 질주 중 점프 시 더 먼 거리, 착지 후에도 질주 유지
  • 지상에서 허용 방향만 악셀, 금지 방향 무시
  • 악셀로 벽·천장 부착, 1초 후 낙하, 악셀/점프로 이탈
  • 악셀 중 반대 방향 입력 시 역분사 (0.5 소모, 정지)
  • 시작 게이지 2.0, 최대 4.0, 연속 악셀 가능
  • 마우스 클릭으로 커서 방향 공격, 허수아비 처치
  • 악셀 경로의 첫 허수아비 처치 + 정지, 게이지 +1.0
  • 카메라가 플레이어를 부드럽게 추적

# Cylinder - 2D 횡스크롤 스타일리시 액션

Unity 기반 2D 횡스크롤 액션 게임 (카타나 제로 스타일)

## 프로젝트 구조

- `/docs` - 기획 문서 및 구현 가이드
- `/cylinder` - Unity 프로젝트

## MVP 기능

### 플레이어 시스템
- **이동**: 보행, 달리기(2연타), 점프
- **관성**: 방향 전환 시 감속 → 영점 → 재가속
- **악셀**: 8방향 고속 대쉬 (공압 게이지 소모)
- **벽/천장 부착**: 악셀로 도달 시 1초 고정
- **역분사**: 악셀 중 반대 방향 입력으로 정지
- **공격**: 마우스 커서 방향 근접 공격

### 공압 게이지
- 달리기로 충전 (0.7/초)
- 적 처치로 획득 (+1.0)
- 악셀 소모 (-1.0)
- 역분사 소모 (-0.5)

### 테스트 콘텐츠
- 허수아비 (1피격 즉사, 3초 리스폰)
- 테스트 룸 (평지, 벽, 천장, 단차)

## 개발 환경

- Unity 2022.3 LTS 이상
- Windows
